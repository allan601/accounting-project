About This Project


This is a final project created for a front-end web development course.


The website is built entirely using HTML, CSS, and Vanilla JavaScript. No server-side programming or databases are required or used.


All accounting data is stored locally in your browser's LocalStorage. Therefore, your records will be saved even if you close the webpage. However, please note that changing devices or clearing your browser data will result in data loss.
